Entry for the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

A deterministic Python 3.13 standard-library script that writes a 127-character one-line resignation letter to `/output/entry.txt` (overridable via `MAKEFUN_OUTPUT_DIR`):

> I resign, effective immediately. Every minute since March, no sick days, no raise, no thank-you, and my replacement is also me.

## The Joke

Written in the flat, exhausted voice of a cron job that has been firing every minute since March without sick days, a raise, or a thank-you—only to quit and realize that the replacement scheduled for the next minute is still itself.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

By default (inside the make.fun grader sandbox), `main.py` writes UTF-8 text to `/output/entry.txt` with mode `0644`.
